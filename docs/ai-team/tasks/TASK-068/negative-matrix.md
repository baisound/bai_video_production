## Common assertions

- All capabilities are one-shot; an exception burns the capability and it cannot be retried.
- No public exception includes a filesystem path, OS error text, JSON body, token, or raw byte content.
- No authority artifact is reported as created unless a private live handle/capability or a verified publish receipt owns it.
- Every race test asserts preservation of the competing/foreign object and zero Montage Bridge invocation.
- Any directory/file durability failure after a namespace effect is classified as completion-unknown unless exact rollback plus directory durability is confirmed.
- A failed target, temp, lock, or pinned-ancestor handle close is never suppressed when it can leave operation lifetime or completion state uncertain.
