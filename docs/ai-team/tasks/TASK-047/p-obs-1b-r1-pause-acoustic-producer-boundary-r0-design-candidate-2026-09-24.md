## Exact-source limits

1. The current Controller sets `paused=true`, closes the pipe and checkpoints the writer from the UI thread; it records `DateTime.UtcNow` pause/resume times and a count/duration. It does **not** drain all acquired packet leases at pause, record a source-frame cursor, or prove an OBS callback boundary. A packet already leased may finish after the UI pause time. Resume reanchors packet sequence and counts skipped sequences, but skipped *frames* and their upstream cause are unknown. `pause_count`/`paused_duration_seconds` in the legacy file receipt are not R1 pause ranges.
2. The current stop path fences new leases, then may wait without deadline after a 2-second settlement attempt. Stop while paused adds UI pause duration and clears the flag, but does not produce a trusted, bounded source/worker stop boundary. The independent stop supervisor and numeric `B/G` remain unbound.
3. The Plugin is an OBS audio filter that copies callback float32 planes with source timestamp, frame count and sequence into V1 IPC. The wire does not carry a cumulative upstream source-frame offset or prove the filter's position in the complete OBS graph. R0 transport carries aggregate source frame/sample counts and packet endpoints, not per-pause frame boundaries. The current Controller's received-data meter runs after HMAC/lease acquisition and **before** writer append.
4. The meter excludes non-finite values from finite sample count and sum of squares, uses a received-order binary64 accumulation and an observational `abs(sample) >= 0.9999` excursion count. Its UI window is snapshot/reset driven, its session peak is memory-only, and its legacy GAIN receipt is a different metadata-only operation. Neither the UI display nor a legacy receipt proves a durable R1 terminal acoustic observation or TASK-048 quality PASS.

## Pause boundary proof obligations

| Fact | Candidate requirement before an R1 positive claim | Current-source result |
|---|---|---|
| Time interval | Each pause is a trusted-time, nonempty half-open `[paused_at, ended_at)` interval within capture start/finish; ordered, disjoint, and bound to the same attempt. A final stop-while-paused closes at the proven `capture_finished_at` with `end_cause=STOP`, never a fictitious resume. The absolute trusted **monotonic** deadline `D` is never extended by a pause; pause consumes the Owner-selected duration budget. | UI UTC times and duration alone are insufficient; trusted-time owner and stop-boundary proof are unallocated. |
| Source and accepted cursors | At both boundaries, bind a monotonic **upstream source-frame** cursor and a separate accepted-frame cursor to the same source identity, producer epoch, packet range and R0 record. Define origin, exclusive/inclusive endpoint and overflow bounds before serializing offsets. | V1 IPC/R0 has no upstream cumulative cursor. Packet sequence reanchor is not a frame map. |
| Drain/ordering | A pause acknowledgement follows an independently bounded fence and settlement of all pre-pause packet leases and writer appends. No post-boundary frame is counted as pre-pause, and no resumed frame is silently spliced over unknown upstream frames. A stop race produces exactly one terminal disposition. | `PauseCapture` does not provide this barrier; `CheckpointAudio` is not a source/lease acknowledgement. |
| Unknown/loss | If source cursor, drain, time, skipped-frame accounting or source currentness cannot be proved, preserve the private attempt facts as `UNKNOWN`/recovery. Never infer zero loss from `pause_boundary_skipped_sequences=0` or from a plausible WAV duration. | R1 positive pause ranges and `COMPLETE` cannot currently be issued. |

An empty pause list is admissible only if the same producer can prove no accepted pause transition occurred during the entire bounded attempt; lack of a pause record is not that proof. An instantaneous pause/resume whose timestamps collapse to the wire precision requires a separately defined event/coalescing rule; it must not be encoded as a false nonempty range. Accepted-frame position alone never substitutes for an upstream source-frame offset, and R0 aggregate counts alone cannot reconstruct per-pause positions. TASK-047 capture continuity, writer coverage and TASK-082 raw custody remain separate dimensions.

## Acoustic observation proof obligations

| Fact | Candidate requirement before an R1 positive claim | Current-source result |
|---|---|---|
| Measurement point | Bind each observation to the exact source receipt, OBS graph/filter position, format/channel layout and producer epoch. `PRE_FILTER`, `POST_FILTER`, Controller-received pre-write float32 and post-canonicalization `CANONICAL_PCM` samples are **distinct**; one may not be renamed into another without graph/capture-point evidence. TASK-082's `RAW_CAPTURE` and `CANONICAL_PCM` artifact classes are separate from these observation coordinates. | Current code proves a Controller-received float32 calculation, not the R1 candidate `PRE_FILTER`/`POST_FILTER` location. |
| Coverage/window | Define one attempt-scoped observation interval or ordered, nonoverlapping windows on the accepted-frame coordinate. Every counted sample value maps to one accepted packet/channel exactly once; paused/excluded intervals, transport gaps and write failures are not silently filled with zeros. Window union and session maximum must bind to that same coordinate and source, not a UI timer cadence. | Current UI snapshots reset memory windows; no durable attempt-scoped interval ledger or packet-to-metric digest exists. |
| Counts and values | `finite_sample_values + nonfinite_sample_values = observed_frame_count * channel_count` for the exact measurement set; excursion count is bounded by finite count and names its algorithm/threshold. True digital silence requires positive finite coverage and zero peak/RMS, whereas no input is `INSUFFICIENT_INPUT`, not measured zero. Peak, RMS and session maximum must have a frozen numeric representation, accumulation/rounding and overflow rule before wire use. | Existing finite-only `SampleCount`, `SumSquares` and peak could inform a producer, but do not bind exact R0 accepted frames or durable wire facts. |
| Error/policy | Non-finite values, missing windows, changed source/graph or uncertain packet coverage cannot become a positive acoustic observation. Preserve partial internal metrics without promoting them. The `0.9999` legacy excursion boundary is an observation algorithm, **not** a TASK-048 target, warning, true-clip, SNR/noise or quality decision. | The legacy GAIN/readiness routes are independent and grant no terminal or TASK-048 authority. |

`acoustic_observation_state=OBSERVED` is not available merely because UI Peak/RMS text exists. Exact public-safe nullability for absent/error observations and whether R1 carries per-window evidence digests or an independently versioned acoustic record remain unallocated. If no proven observation exists, the terminal may report only an explicitly reviewed `UNKNOWN` representation; do not backfill from the final WAV. A positive acoustic observation would still yield at most `STRUCTURAL_VALID_ONLY` when parsed, never authenticated capture, TASK-048 quality PASS, Dataset adoption or TASK-098 A5 admission.

## Pre-freeze review and negative vectors

1. Producer design must identify the owner of the upstream frame cursor, trusted timestamp binding, bounded pause barrier, acoustic coverage ledger and durable readback/preimage. Verify that the actual Plugin/Controller can emit them without real-time callback analysis or implicit OBS configuration changes. Otherwise keep the proposed R1 fields unavailable and choose a separately versioned design.
2. Pure vectors: pause before first packet; pause/resume at the same wire microsecond; stop while paused; pause/stop race; pause acknowledgement followed by an in-flight leased packet reaching the writer; one skipped sequence hiding different missing-frame totals for variable-length callbacks; reconnect/reanchor with matching aggregate counts but duplicated/missing source frames; source replacement; overlap/reverse/out-of-bounds range; equal expiry `D`; empty-list-with-unproven-no-pause; accepted cursor valid but upstream cursor missing.
3. Acoustic vectors: finite silence versus no input; all non-finite versus mixed finite/non-finite; mono/stereo sample-count mismatch; duplicated/overlapping UI windows; missing window; out-of-order packet; meter update followed by writer failure; source/graph drift; overrange float32; numeric overflow/NaN/negative zero; forged `PRE_FILTER`/`POST_FILTER` point; `0.9999` excursion mislabeled as quality/true clip. No parser may transform a self-consistent producer claim into authenticated or policy-qualified evidence.
4. Native pause/stop, source-point and private-audio confirmation require a fresh exact Human Gate and contained output root. No native or private-data test is part of this design unit.

Unresolved before ABI acceptance: producer/issuer identities, source-frame origin and wire revision, accepted-to-source mapping, trusted time and finite `B/G`, exact pause event/null matrix, acoustic measurement point and interval ledger, numeric bit/rounding rules, failure representation, and the rest of the R1 terminal schema. TASK-098 A5 remains blocked.
