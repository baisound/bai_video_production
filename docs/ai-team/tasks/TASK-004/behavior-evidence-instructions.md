- The active Audacity project must be completely empty before the command starts.
- Do not open or import client/production media during the probe.
- ComfyUI is not required for this probe.
- The probe creates its own 48 kHz stereo WAV inputs and isolated Product Job/Asset roots under `task004-live-evidence-behavior/`.
- Do not manually operate Audacity while the probe is running.
- If the probe fails or times out, do not immediately rerun it. Return the Evidence directory for review. A post-dispatch timeout is retained as an ambiguous `PARTIAL` state so Product will not blindly repeat external AI work.
