## TASK-006 profile re-evaluation

The next TASK-006 slice introduces resumable large-media transcription
state/checkpoints and a canonical Resolve subtitle-placement handoff.

It is classified `DEV-3` because resume integrity, deterministic state,
filesystem publication and downstream NLE contract errors can corrupt or
duplicate long-running work. It is not `DEV-4` because it does not change
Product authority, the global ProductionJob state machine, authentication, or
irreversible external writes.

Required for that slice:

- detailed design and acceptance criteria;
- focused regression while implementing;
- Critic review focused on resume integrity, privacy and timeline correctness;
- full Product regression before handoff;
- no actual Resolve write inside TASK-006; execution remains TASK-010-owned.
